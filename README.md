# Trabalho de Scripting

Este trabalho foi realizado no âmbito da disciplina de Linguagens de Scripting.

## Parte 1 - Bash
Script para organizar ficheiros automaticamente por tipo (txt, imagens, logs).

## Parte 2 - Web Scraping
Script em Python para recolha de títulos de notícias de um site público.

## Parte 3 - API
Script que consulta dados meteorológicos atuais usando a API Open-Meteo.

## Execução
python scraping.py  
python api.py
